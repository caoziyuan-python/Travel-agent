# 功能需求与边界

## 用户画像

| 画像 | 特征 |
|------|------|
| 来京游客 | 首次或多次来北京，需要景点推荐、交通指引 |
| 自由行规划者 | 自己安排行程，需要个性化推荐与多日规划 |
| 短期出差人员 | 时间有限，需要高效的附近餐饮/景点推荐 |

---

## 核心功能

### F1 景点 / 餐厅 / 酒店推荐
- 按类别（景点、餐厅、酒店、购物、交通枢纽）搜索北京 POI
- 支持按距离、评分、关键词筛选
- 数据来源：高德地图 POI API

### F2 路线规划
- 支持四种交通方式：驾车、步行、骑行、公共交通
- 输出：预计时间、距离、费用（公交/打车）、关键节点
- 数据来源：高德路线规划 API

### F3 实时天气
- 查询北京当日及未来天气
- 数据来源：高德天气 API

### F4 旅游攻略问答
- 基于小红书真实用户游记回答攻略类问题
  - 例："故宫有什么拍照技巧？""天坛公园几点开门最合适？"
- 数据来源：local_rednote_agent 实时检索

### F5 个性化行程生成
- 根据用户偏好（天数、兴趣类型、预算）生成完整行程
- 综合 F1–F4 工具的输出，由 GPT-4 生成自然语言行程方案

---

## 功能边界（一期不做）

| 不做的功能 | 原因 |
|-----------|------|
| 机票 / 酒店预订 | 需要接入第三方预订平台，超出当前范围 |
| 实时票价与库存 | 景区票务数据来源复杂，暂不接入 |
| 北京以外城市 | 一期聚焦北京，确保数据质量 |
| 多语言支持 | 一期仅支持中文 |
| 用户账号体系 | 无需登录，无历史记录持久化 |
| 地图可视化 | 前端可选扩展，不在后端范围内 |

---

## 非功能需求

| 指标 | 要求 |
|------|------|
| 响应时间 | Agent 单次对话 < 10s（含 LLM 调用） |
| 工具调用 | 支持同一轮对话多工具并发调用 |
| 安全性 | API Key 通过环境变量管理，不硬编码 |
| 可扩展性 | 新增工具只需在 `agent/tools/` 添加函数并注册，无需改动核心逻辑 |
| 错误处理 | 工具调用失败时 Agent 返回友好提示，不崩溃 |
